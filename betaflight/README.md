# Betaflight TX Lua Scripts 1.8.0

Copia **sin modificar** de [betaflight/betaflight-tx-lua-scripts](https://github.com/betaflight/betaflight-tx-lua-scripts) (release 1.8.0), tal como está instalada en mi Pocket. Licencia GPL-3.0 (ver `LICENSE`). El código es de sus autores; aquí solo está para tener mi setup completo. Para la versión más nueva, descárgala del repo original.

**Instalación:** copia el contenido de `SCRIPTS/` a la carpeta `SCRIPTS/` de la SD. Para abrirlo: SYS → Tools → Betaflight setup. Con eso puedes cambiar PIDs, rates, VTX y más desde la radio.
